# 文章风格参考：三种"看着舒服"的公众号风格（2026-08-09）

> 用户提供三篇参考文章，分别代表三种舒服的风格。本文档提取每种风格的结构
> 特征与适用场景，作为文章产线 style 约束的参考基线。
> 素材归档：marketing/evidence/style-refs-2026-08-09/

---

## 风格 1：研究策展清单型（ref1）

- 原文：《[Research Curation] AI 网络安全实战能力测评 Benchmark：从 CTF 到真实漏洞利用的 25 篇 Benchmark 论文》
- 结构：一句话导语 → 表格/清单（年份 | 论文 | 简述）→ 分类汇总
- 特征：
  - 高信息密度，一篇顶 25 篇——读者收藏价值极高
  - 表格是主体，每行一个条目，简述 1-2 句
  - 数据驱动：具体数字（110 个漏洞、920 个 CVE、41 个 V8 漏洞）
  - 无废话导语，直接进入清单
- 适用：赛道 C（Agent 治理数据向）、月度盘点、Benchmark 汇总
- 舒服点：**信息密度 + 可收藏**。读完有"这份清单我得存着"的感觉

## 风格 2：概念辨析短文型（ref2）

- 原文：《多Agent为何要Graph》（系统与旷野）
- 结构：现象（大家混为一谈）→ 三个概念逐一辨析（Harness/Loop/Graph）→ 记忆法（环境/反馈/流向）→ 决策建议
- 特征：
  - 全文仅 609 字，短小精悍
  - 每个概念一段：定义 + 边界 + 一句话记忆法
  - 结尾给可操作判断（"环境不稳，先别画复杂 graph"）
  - 配图说明（图文混排）
- 适用：概念澄清、术语辨析、认知纠偏——读者正困惑的话题
- 舒服点：**短 + 清晰 + 有结论**。读完马上能记住"Harness 是环境，Loop 是反馈，Graph 是流向"

## 风格 3：深度技术翻译整理型（ref3）

- 原文：《GAP — Ghost Anchor Persistence: Fileless Extension Persistence in Chromium Browsers》（Fir3n0x，2026-05-10）
- 译文：《GAP — 幽灵锚点持久化：Chromium 浏览器中的无文件扩展持久化》
- **性质：翻译文章**——保持内容与原文一致，学习重点是**内容整理方式**（怎么把长技术原文整理成清晰结构），不是原创写作
- 结构（原文↔译文逐节对应，忠实保留）：攻击面引子 → 前置工作（stomp）→ 三个关键组件 → 攻击原语（四步感染链）→ 为何永不过期 → 红队价值 → 负责任披露 → PoC/免责声明
- 特征：
  - **章节一一对应**：译文结构完全跟随原文，不增删主体内容
  - **长段拆短**：原文大段落拆成"短段 + 关键概念单独成行/加粗"（如"恶意扩展文件夹留在磁盘上"独立成行强调）
  - **术语处理**：技术名词保留英文（Secure Preferences / ScriptCache / version_id），首次出现给中文说明（GAP=幽灵锚点持久化）
  - **路径/命令代码化**：文件路径、API 名、缓存键用代码块（C:\Users\...\Secure Preferences、chrome-extension://<ID>/background.js）
  - **列表化**：红队价值 6 条、agent 能力清单，原文 bullet 转中文 bullet
  - **关键洞察加粗**："替换磁盘上的扩展文件夹不会触发失效""不验证缓存脚本是否匹配"
  - **图表保留**：原文 ASCII 架构图（Extension ID → folder B → ScriptCache）原样保留
  - **免责声明保留**：文末教育/研究目的声明
- 适用：赛道 A/B 的海外一手技术研究翻译（wunderwuzzi23、Fir3n0x、OWASP 等英文源）
- 舒服点：**结构清晰 + 忠实原文 + 术语准确**。读者获得完整技术认知，译者不夹带私货

## 三风格对照

| 维度 | 风格1 策展清单 | 风格2 概念辨析 | 风格3 翻译整理 |
|---|---|---|---|
| 篇幅 | 长（50KB 素材） | 极短（~600字） | 中长 |
| 核心 | 清单/表格 | 辨析/记忆法 | 忠实原文+结构整理 |
| 密度 | 高（一篇顶 N 篇） | 高（一字千金） | 高（技术密集） |
| 情绪 | 中立收集 | 启发顿悟 | 真实可信 |
| 读者动作 | 收藏 | 转发讨论 | 反复研读 |
| 对应赛道 | C 数据向/盘点 | 概念澄清 | A/B 一手研究翻译 |

## 对产线的含义

1. **三种风格都该有**：产线每周 2-3 篇可按风格轮换——风格 2（短文辨析）适合
   穿插在 A/B 深文之间做节奏缓冲，风格 1（策展清单）适合月度/季度盘点。
2. **风格 2 是当前产线的盲区**：现有约束 C5 按赛道定长度（A 800-1500），
   风格 2 的 600 字短文没有对应位置——考虑加"短文辨析"类型（500-800 字）。
3. **共同点 = 用户说的"舒服"**：信息密度高、无废话、有结论、真实感
   ——这与现有 C1-C9 约束方向一致，验证了约束 v1 的正确性。
4. **风格 3 是翻译整理，不是原创**：GAP 译文忠实原文、逐节对应，学习点是
   "长段拆短 + 术语保留 + 列表化 + 图表保留"的内容整理方式（已固化为 C10）。
   产线做赛道 A/B 的海外一手研究时走翻译通道；自研内容（蜂群、H1 战绩）
   才是原创通道——两条线分开，避免翻译夹带私货或原创被误当翻译。
