# AI 工程从零开始 — 中文教育内容项目

## 源材料
- GitHub: https://github.com/rohitg00/ai-engineering-from-scratch
- 503 节课, 20 个阶段, Python/TypeScript/Rust/Julia
- MIT 开源, 月活 15 万读者

## 目标
将这套课程转化为适合中国读者的教育内容矩阵：
- 微信公众号连载文章
- 知乎深度技术专栏
- B站代码教程视频
- CSDN/掘金技术文章
- 小红书知识卡片引流
