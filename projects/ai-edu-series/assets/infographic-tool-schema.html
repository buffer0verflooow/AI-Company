FIG_02.01 — TOOL SCHEMA DESIGN PHASE 02

工具 Schema 三要素：让模型准确选对工具

一条 Schema 定义的好坏，直接决定 Agent 能不能用对工具
①
工具名
name
# ✅ 好命名：动词-名词, 层级清晰
"search_contacts"
"notes_create"
"weather_get_forecast"

# ❌ 坏命名：单一名词, 无意义前缀
"search"
"tool1"
"create"
snake_case camelCase 命名空间前缀 单一名词
命名即定位。模型通过名字快速排除不相关工具。名字模糊 → 批量误调用。
②
工具描述
description
# ✅ 好描述：Use when + NOT when
"Use when user asks to search
contacts by name or phone.
Do not use for email lookup —
use search_emails instead."

# ❌ 坏描述：一句带过, 无排他信息
"Search contacts."
模型只读 description来决定调用哪个工具。 描述模糊 → 准确率 62%  描述清晰 → 89%
③
参数定义
input_schema
// JSON Schema — 精确约束
{
  "type": "object",
  "properties": {
    "unit": {
      "type": "string",
      "enum": ["celsius",
             "fahrenheit"]
    }
  },
  "required": ["unit"]
}
enum 封闭集合 type:any 通配 required 必填 无 description
参数越精确，幻觉越少。enum 封闭可选值，required 标记必填字段 —— 让模型无法「编造」参数。
📈
62% → 89%
工具描述质量对工具选择准确率的影响
⚠️
15–30%
单体工具（一个 tool 包所有功能）相比原子化工具的精度损失
