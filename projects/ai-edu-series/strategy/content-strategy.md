## 1. 项目定位与受众分析

### 1.1 一句话定位

> **「从零手写 AI 全栈」——用 20 篇文章，带你从线性代数一路写到多智能体集群，每篇都能跑、能改、能放进简历。**

### 1.2 目标受众画像

| 受众类型 | 占比估计 | 典型特征 | 核心诉求 |
|---------|---------|---------|---------|
| **AI/ML 开发者（1-3年）** | 35% | 会用 PyTorch/TensorFlow 调包，但说不清反向传播内部机制 | 补齐基础，理解原理，突破瓶颈 |
| **计算机专业学生** | 30% | 系统学过数学/算法，但没接触过产业级 AI 工程链路 | 建立从理论到工程的完整认知 |
| **后端/全栈转 AI** | 20% | 工程能力强，缺数学和 ML 基础 | 最短路径切入 AI 赛道 |
| **AI 产品 / 技术管理者** | 10% | 需要判断技术可行性，但不写代码 | 理解技术边界，建立技术判断力 |
| **高校教师 & 培训讲师** | 5% | 寻找结构化教学素材 | 获取高质量可复用的教学内容 |

### 1.3 受众痛点（内容要打中这些点）

1. **碎片化学习无效**——看了无数篇公众号/知乎/B站，还是拼不出完整知识体系。
2. **调包工程师天花板**——`import torch` 能跑，但面试一问「Attention 的 QKV 是怎么算的」就哑火。
3. **数学恐惧症**——知道线性代数重要，但不知道和 AI 有什么关系。
4. **工程落地无能**——能训出模型，但不知道怎么部署、监控、做安全。
5. **跟不上 SOTA**——2026 年的 Agent、MCP、DeepSeek-V3 架构不知道怎么补。

### 1.4 主平台策略

| 平台 | 优先级 | 内容形态 | 核心作用 |
|-----|-------|---------|---------|
| **微信公众号** | ⭐⭐⭐⭐⭐ | 深度长文（5000-8000字/篇） + 代码截图 | 主阵地，建立深度技术品牌 |
| **知乎** | ⭐⭐⭐⭐ | 公众号文章同步 + 问答引流 | SEO 长尾 + 技术社区影响力 |
| **B站** | ⭐⭐⭐⭐ | 配套视频（源码走读 + 可视化演示） | 触达学生群体，补视觉效果 |
| **CSDN** | ⭐⭐⭐ | 公众号文章同步 | 搜索引擎收录 + 开发者社区 |
| **掘金** | ⭐⭐⭐ | 精简版 + 代码高亮 | 前端/全栈转 AI 群体的入口 |
| **小红书** | ⭐⭐ | 图文摘要 + 学习笔记模板 | 年轻受众 + 学习打卡传播 |

## 3. 内容形式与文章结构模板

### 3.1 标准文章结构（每篇 5000-8000 字）

```markdown
# [Phase X]：[中文标题]
> [一句话金句/核心洞察]

## 📋 本篇纲要（150字）
- 列出 3-5 个你将获得的能力/知识
- 标注对应的源课程链接

## 🔥 为什么这件事重要（300-500字）`← 对应 MOTTO + PROBLEM`
- 用一个真实场景/痛点开篇
- 对比「不懂原理」vs「懂了原理」的差别
- 给读者一个读完的理由

## 🧠 核心概念（2000-3000字）`← 对应 CONCEPT`
- 分层讲解：直觉 → 图解 → 公式 → 代码
- 每个概念不超过 3 个子点，避免信息过载
- 大量使用类比（数据库查询、地图导航等）
- 穿插 Mermaid 流程图/架构图

## ✍️ 手写实现（1500-2000字）`← 对应 BUILD IT`
- 核心代码片段（带详细中文注释）
- 关键决策解释（为什么选这个实现方式）
- 运行结果截图/输出
- 常见踩坑记录

## 🚀 拿来就用（500-800字）`← 对应 USE IT + SHIP IT`
- 对应工业级库的使用方法（PyTorch/scikit-learn 等价实现）
- 本期产出物展示和使用说明
- 可下载/可复制的代码/脚本链接

## 🔮 下期预告（200字）
- 引出下一篇内容和关联性
- 制造悬念

## 📚 延伸阅读（可选）
- 源课程链接
- 推荐论文/书籍
```

## 5. 内容差异化策略

### 5.1 市场竞争格局

当前中文 AI 教育市场的主要问题：

| 竞品类型 | 代表 | 优点 | 致命缺陷 |
|---------|------|------|---------|
| **快餐类公众号** | 各种「5 分钟学会 xxx」| 短平快，阅读门槛低 | 碎片化，学完什么都不会 |
| **学院派课程** | 吴恩达、李宏毅、CS231n | 系统、权威 | 英文+视频为主，缺少工程视角 |
| **框架文档翻译** | PyTorch 中文文档、HuggingFace 教程 | 实用 | 只会调包，不懂原理 |
| **付费训练营** | 各种 9999 元 AI 班 | 有助教、有作业 | 贵且质量参差不齐，收割焦虑 |
| **技术公众号** | 宝玉、李丁等 | 信息密度高 | 零散不系统，无法构建体系 |

### 5.2 我们的独特卖点（USP）

#### USP 1：「从零到集群」的完整系统性格局

> 市面上没有第二套内容能覆盖「线性代数 → 反向传播 → Transformer → LLM → Agent → 多智能体」的完整链路。

- 大多数 AI 教程止步于「用 PyTorch 训练一个分类器」
- 本系列一路写到 Phase 19 的自主科研 Agent 和多智能体集群
- 读者可以从任意一篇切入，且每篇之间的前后关联清晰

#### USP 2：「每个概念都有手写实现」

> 不是「import torch.nn as nn」，而是「自己写出 nn.Linear 内部发生了什么」。

- 遵循源课程的 BUILD IT → USE IT 双轨制
- 每篇文章都包含可运行的「手写版」代码
- 读者看完不仅能说，还能写——这是面试和工作的最大分水岭

#### USP 3：「开源项目背书 + 中文本地化」

> 不是凭空编造的内容，而是基于 GitHub 15 万+ 读者的开源项目，经中文重述和本土化。

- 源项目已有 150,639 读者，241,669 月 PV
- 中文版不是翻译，而是重述：替换中文语境案例、加入国内技术栈对比
- 每篇都可以回溯到源课程的 en.md——信用和权威性有背书

#### USP 4：「产出物导向——每篇都带走一个工具」

> 不是一个「恭喜你学会了」的结尾，而是一个可安装、可使用的 Prompt/Skill/Agent。

- 源课程 503 个可复用产出物
- 每篇文章精选 1-2 个，提供中文使用说明
- 读者可以积累自己的 AI 工具箱

#### USP 5：「工程视角，而非学术视角」

> 不是从论文出发，而是从「如果你要在生产环境做这个，你需要知道什么」出发。

- 每篇文章的「为什么重要」部分从真实工程痛点切入
- 注重性价比（什么时候用简单方案，什么时候上复杂方案）
- Phase 17（生产部署）、Phase 18（安全合规）都是纯工程视角

### 5.3 差异化定位一句话

> **「市面上唯一的、体系完整的、有手写代码的、工程视角的中文 AI 全栈教育内容。」**

### 5.4 差异化执行要点

1. **中文语境案例**: 将源课程中的英文案例替换为中文场景（中文分词、中国互联网产品、国内云平台）
2. **国内技术栈对比**: 在框架选择时，对比国内常用的 PaddlePaddle、MindSpore 等
3. **面试导向补充**: 每篇加入 2-3 个面试高频问题及解答思路
4. **「如果在中国落地」视角**: 在工程部署、安全合规篇加入中国监管环境（生成式 AI 管理办法、数据出境等）
