**核心机会点：**

1. **体系化AI工程课程空白**：目前B站没有从"数学基础→深度学习→LLM→Agent工程→生产部署"的全栈体系课程

- vs 李沐：更工程化、更代码驱动、更多前沿Agent内容

- vs 莫烦/唐宇迪：系统性更强、覆盖到2026年前沿

## 4. 视频内容形式策略

### 4.1 主推荐形式：代码录屏 + 中文画外音讲解（主力形式）

**为什么选这个：**
- 课程本身就是代码驱动的，"Build It"环节天然适合录屏
- 画外音（非真人出镜）降低制作门槛，便于批量生产
- B站AI教程区观众习惯代码录屏，接受度高
- 制作成本低，适合503节课的大体量

**具体执行标准：**
- 屏幕：VS Code 暗色主题 + 大字号（16-18px）
- 画外音：专业级AI配音（如Azure TTS 或 ElevenLabs 中文）+ 或真人录音
- 节奏：写一段代码 → 讲解一段 → 运行看结果 → 讲解输出
- 时长控制：10-20分钟/期（B站AI教程最佳时长区间）
- 章节标记：进度条加章节节点（B站互动功能）

### 4.2 辅助形式一：动画图解（概念讲解用）

- 用于讲解抽象概念（如反向传播、注意力机制、Transformer架构）
- 使用 Manim（3B1B同款引擎）制作数学动画
- 每个Phase开头可以有一期"Phase概览"动画视频
- 这类视频更容易出圈，吸引非技术观众

### 4.3 辅助形式二：真人出镜（里程碑节点）

- 仅在关键节点出镜：频道启动、Phase完成总结、重大更新
- 建立"人"的信任感，拉近与观众距离
- 可以邀请嘉宾（如开源社区贡献者）做访谈

### 4.4 形式配比

```
代码录屏+画外音 ████████████████████████████████  80%
动画图解         ████████                          12%
真人出镜         ███                                5%
直播答疑         ██                                 3%
```

### 4.5 视频结构模板（单期15分钟）

| 时间段 | 内容 | 说明 |
|--------|------|------|
| 0:00-0:30 | 开场Hook | "上期我们手写了X，今天我们来造Y" + 本期产出预览 |
| 0:30-1:30 | 概念讲解 | 模型/动画图解关键概念，讲清楚"为什么" |
| 1:30-8:00 | BUILD IT | 从零手写，一行一行敲，边写边讲 |
| 8:00-11:00 | USE IT | 用PyTorch/sklearn调库实现相同功能，对比差异 |
| 11:00-13:00 | SHIP IT | 展示产出物（Prompt/Skill/Agent）在实际场景中的使用 |
| 13:00-14:30 | 总结 | 核心收获 + 下期预告 |
| 14:30-15:00 | CTA | "点赞收藏关注，下期见" |

### 6.2 标题策略

#### 标题公式

```
[动作词] + [核心概念] + [从零手写] + [产出/结果]
```

#### 标题模板库

| 类型 | 模板 | 示例 |
|------|------|------|
| **教程型** | 【从零手写】XXX，N行代码实现XXX | 【从零手写】Agent Loop，120行纯Python实现ReAct |
| **对比型** | 手写XXX vs 调包XXX，差距有多大？ | 手写Attention vs torch.nn.MultiheadAttention |
| **揭秘型** | XXX底层到底是怎么工作的？手写一遍就懂了 | GPT的Self-Attention到底怎么算的？ |
| **挑战型** | 不用框架，N行纯Python实现XXX | 不用PyTorch，200行实现完整Transformer |
| **产出型** | 这期学完，你就能XXX | 这期学完，你就能部署自己的MCP Server |

#### 标题优化原则

- ✅ 包含具体数字（120行、3步、15分钟）
- ✅ 明确学习收益（"你就能..."）
- ✅ 使用B站高CTR词汇：手写、从零、原理、底层、实战
- ❌ 避免标题党（"震惊！""99%的人不知道"）
- ❌ 避免过度夸张（"看完直接进大厂"）
- ❌ 避免纯英文标题（影响搜索）

### 6.3 缩略图A/B测试

每期制作2版缩略图，前24小时看CTR数据，用高CTR版本替换低版本。

## 7. 弹幕与评论区互动策略

### 7.1 弹幕运营

**弹幕是B站视频的"第二内容层"，好的弹幕互动大幅提升完播率。**

#### 主动埋"弹幕钩子"

在视频关键节点设置互动引导：

| 时机 | 引导语 | 预期弹幕 |
|------|--------|----------|
| 讲到核心公式时 | "弹幕扣1，我看看多少人跟上了" | 弹幕刷"1" |
| 代码运行成功时 | "觉得神奇的扣个666" | 弹幕刷"666" |
| 对比手写和框架结果时 | "一模一样对吧？弹幕打'一模一样'" | 弹幕刷相应内容 |
| Bug调试时 | "这里我犯了个错...你们发现了没？" | 弹幕指出错误 |
| 结尾提问 | "下期想看什么？Attention还是Transformer？" | 弹幕投票 |

#### 弹幕维护

- 前3天每天看弹幕，回复技术问题的弹幕（用评论回复功能）
- 适当添加UP主弹幕（金色弹幕）做关键注释或纠错
- 对明显错误的弹幕做友善纠正

### 7.2 评论运营策略

| 优先级 | 评论类型 | 响应策略 | 响应时间 |

#### 评论区运营动作

1. **UP主置顶评论**：每期准备一条"课代表总结"置顶评论

   ```
   📝 本期核心：
   1. Agent Loop = while True: llm(history) + tool_calls
   2. 完整代码见GitHub: github.com/rohitg00/ai-engineering-from-scratch
   3. 前置知识：P14前需先看P7 Transformer + P11 Function Calling
   
   ⏱ 时间戳：
   00:45 概念讲解
   02:30 Build It 从零手写
   08:15 Use It 调包对比
   ```

2. **评论区技术讨论引导**：抛出开放性问题
   - "大家觉得Agent Loop里最大步数设多少合适？"
   - "你们在实际项目里用过MCP吗？体验怎么样？"

3. **"交作业"激励**：鼓励观众在评论区贴自己的代码输出
   - 优质作业点赞置顶
   - 可以每10期选一个"最佳作业"做一期Review

### 9.2 数据驱动优化流程

```
发布视频
  ↓
24h内：看CTR（点击率）→ 低于6%就换封面/标题
  ↓
72h内：看完播率曲线 → 找出观众流失点 → 调整下期内容编排
  ↓
7天内：看评论关键词 → 了解用户真实需求
  ↓
14天内：看收藏/投币比 → 判断教程长期价值
  ↓
30天：复盘一个Phase的数据 → 优化下一Phase方案
```

### 9.3 B站算法友好策略

- **固定更新频率**：每周二、四、六 晚上20:00发布（B站流量高峰）
- **互动率**：前1小时回复弹幕和评论（提升初始互动分）
- **合集完整度**：一个合集至少5期再公开（B站推荐完整合集）
- **时长**：12-18分钟是最优区间，太短没深度，太长影响完播
- **话题标签**：使用热门标签（#AI #编程 #深度学习 #从零开始）
