- **人群**：AI 工程师、算法工程师、全栈开发者、ML 在校生、转行 AI 的软件工程师

**推荐**：「AI工程从零开始」—— 与源仓库 README 翻译名一致，SEO 友好，知乎/CSDN/掘金跨平台统一品牌。

## 二、文章排版规范

### 2.1 标题层级规范

```
一级标题（文章标题）：24-28px，加粗，深色 #1a1a1a
二级标题（Phase 阶段）：18-20px，加粗，主题色 #3553ff（与源项目品牌色一致）
三级标题（Lesson 主题）：16px，加粗，深灰色 #333333
正文：15px，#3f3f3f，行间距 1.75，段间距 1 空行
```

**标题公式**：`[阶段编号]｜[阶段名称]｜第X课：[课程标题]`

示例：
- `Phase 3｜深度学习核心｜第3课：从零手写反向传播`
- `Phase 10｜从零构建 LLM｜第4课：预训练一个 Mini GPT (124M 参数)`

### 2.2 导语/摘要规范（每篇文章必备）

在正文前加一段 60-100 字的「导语框」，用符号线分隔：

```
——————— ✦ 今日课程 ✦ ———————

📌 目标：用 120 行纯 Python 实现一个不依赖任何框架的反向传播算法
⏱️ 预计阅读：12 分钟
🛠️ 语言：Python
📦 产出：一个可复用的反向传播 Prompt 模板

—————————————————
```

### 2.3 正文六段式结构（对齐源课程 MOTTO → SHIP IT 流程）

每篇文章严格遵循六段式：

| 段落 | 中文名 | 内容 |
|------|--------|------|
| 🏷️ MOTTO | 一句话核心 | 用最精炼的中文提炼本课要解决的核心问题 |
| ❓ PROBLEM | 痛点引入 | 为什么需要这个算法/技术？不学会有什么后果？ |
| 🧠 CONCEPT | 概念图解 | 用流程图/示意图解释核心直觉（mermaid 或手绘图） |
| 🔨 BUILD IT | 从零实现 | 纯 Python（不含任何框架），逐步手写核心代码 |
| 🚀 USE IT | PyTorch 对照 | 用 PyTorch/sklearn 实现同一功能，对比差异 |
| 📦 SHIP IT | 产出工具 | 展示本课产出的 Prompt/Skill/Agent 模板 |

### 2.4 代码块规范

**公众号代码排版核心痛点**：微信内置编辑器不支持 Markdown 代码高亮，长代码可读性极差。

**解决方案**：

**方案 A（推荐）— Carbon 截图 + 关键代码文字版**
1. 用 [Carbon](https://carbon.now.sh/) 生成带行号和语法高亮的代码截图（主题：One Dark / Dracula）
2. 全文代码 > 15 行 → 用截图
3. 关键代码 < 10 行 → 保留文字版（方便读者复制）

**方案 B — 第三方 Markdown 排版工具**
- 使用 [墨滴](https://mdnice.com/) 或 [WeChat Format](https://lab.lyric.im/wxformat/) 渲染后粘贴
- 主题选择：墨滴「橙心」或自定义暗色系

**代码块样式规范**：
```
语言标识：[Python] [TypeScript] [Rust] [Julia] 前置标签
配色：深色背景 #282c34，浅色文字 #abb2bf
关键词高亮：#c678dd（紫）/ #61afef（蓝）
注释高亮：#5c6370（灰），斜体
行号：左侧 #4b5263，右对齐
```

### 2.5 配图/信息图风格

- **主色调**：#3553ff（源项目品牌蓝）+ #fafaf5（暖白背景）+ #1a1a1a（深黑文字）
- **辅助色**：数学阶段用 #e06c75（暖红），代码阶段用 #61afef（冷蓝），Agent 阶段用 #98c379（绿）
- **图表工具**：Mermaid（流程图）、Excalidraw（手绘风格架构图）、Matplotlib（数据图）
- **封面图**：统一模板，左侧阶段编号 + 名称，右侧课程主题，底部小字「AI 工程从零开始 · 第 X 课」
- **尺寸**：封面 900×383 px（2.35:1），文中插图宽度 640px

## 四、粉丝增长路径

### 4.1 增长漏斗总览

```
曝光层        互推 / 知乎引流 / 技术社区分发 / 搜索 SEO
   ↓
关注层        关注自动回复 → 路线图引导 → 内容价值锚定
   ↓
活跃层        每周推送 → 留言互动 → 读者问答专栏
   ↓
转化层        社群沉淀 → 知识星球 → 付费内容
```

### 4.2 渠道一：跨平台内容分发引流（核心策略）

微信公众号本身是封闭生态，搜索流量有限。需要通过外部平台内容分发建立漏斗。

| 平台 | 策略 | 引流方式 |
|------|------|----------|
| **知乎** | 每篇文章提炼 1 个知乎回答/1 篇专栏文章 | 文末放公众号二维码 +「微信搜索 AI工程从零开始」 |
| **掘金** | 技术向文章全文同步 | 文末 banner 引流 + 个人简介放公众号 |
| **CSDN** | 全量同步 + 百度 SEO | 文末引流，利用 CSDN 百度收录优势 |
| **B站** | 核心算法课录制 10-15 分钟代码讲解视频 | 视频简介 + 评论区置顶引流 |
| **小红书** | 每课提炼 1 张知识卡片（关键公式/代码片段） | 图片水印 + 个人简介引公众号 |
| **即刻/Twitter** | 每课导语（MOTTO）+ 最精彩代码截图 | 个人简介放公众号 |

### 4.3 渠道二：技术社群渗透

- **目标社群**：AI 技术微信群、知识星球、即刻 AI 圈、GitHub AI 项目讨论区
- **渗透方式**：不硬推文章，而是分享单课的最精彩代码片段/概念图解，末尾附「完整教程见公众号」
- **自有社群**：建立读者微信群，按学习阶段分群（入门群/LLM群/Agent群），群内定期答疑 + 学习打卡

### 4.4 渠道三：公众号互推

- **互推对象**：AI 技术号（机器之心、量子位等垂直号的读者画像高度重合）
- **互推形式**：
  - 文末推荐位互换
  - 转载优质单篇（标注来源 + 双方二维码）
  - 联合直播/AMA
- **注意事项**：每 1-2 周一次，保持适度；优先选择粉丝量相近的号

### 4.5 渠道四：搜索 SEO 优化

| 优化点 | 具体做法 |
|--------|----------|
| **标题关键词** | 每篇标题含核心算法名/技术名词（如「反向传播」「Transformer」「RAG」） |
| **摘要** | 文章首段含 3-5 个核心技术关键词 |
| **搜一搜** | 文章内嵌微信小程序可索引内容（如代码片段转文字） |
| **合集标签** | 创建「AI工程从零开始」「LLM」「深度学习」「Agent」等合集话题 |
| **百度SEO** | CSDN + 掘金同步文章，利用平台百度收录权重 |

### 4.6 渠道五：开源社区联动

- 在源仓库 GitHub 提 PR 添加中文版本链接指向公众号
- Gitee 镜像仓库 README 添加公众号二维码
- 课程代码中嵌入公众号二维码注释
- 每篇文章底部 GitHub 链接引导读者去 Star 源仓库

## 五、推送时间和频率建议

### 5.1 推文频率

| 阶段 | 频率 | 理由 |
|------|------|------|
| **冷启动期（第 1-3 个月）** | 每周 3 篇（一三五） | 快速建立内容厚度，积累合集页 |

503 节课，按每周 2 篇计算需要约 5 年才能连载完。建议策略：

- **核心课程（Must-have）**：精选 100-150 篇，覆盖 20 个阶段的核心知识点
- **扩展课程（Nice-to-have）**：剩余课程做付费社群专属内容或知识星球深度文章

## 六、互动策略

### 6.1 留言区管理规范

**精选留言标准**：
- 技术提问 > 心得分享 > 赞美 > 建议 > 其他
- 一个技术提问的出现往往代表 10 个沉默读者也有同样疑问
- 批评性留言也要精选并认真回复（展现开放态度）

**回复时效**：24 小时内回复所有技术类留言

**置顶留言策略**：
- 每篇 1 条置顶：补充说明/勘误/代码仓库链接/社群入口
- 如果某条读者留言质量极高（如补充了更好的实现方式），替换置顶

### 6.2 读者问答栏目

**形式一：每两周一期《你问我答》**
- 收集过去两周留言区的高质量技术问题
- 每期回答 5-8 个问题
- 精选问题提供者赠送课程 Prompt 合集 PDF

**形式二：留言区直接问答**
- 对复杂问题，回复时附「已记录，将在下期《你问我答》中详细解答」
- 简单问题直接回复代码/链接

### 6.3 社群运营策略

**分群结构**：
- **总群**：所有读者，人数上限 500，多个总群
- **进阶群**：完成 Phase 10 以上的读者，更深入的技术讨论
- **打卡群**：自愿参与学习打卡，每周汇报进度

**社群日常**：
- 每周一：发布本周两篇课程预告
- 每周三/五：课程推送后的集中讨论
- 每周末：读者作品展示（读者实现了课程代码并做了改进的案例）
- 每月：优秀学员表彰（完成一个完整 Phase 的读者）

**防沉措施**：
- 新人入群引导：发送欢迎语 + 群规 + 从哪里开始学习的建议
- 每周固定话题引导讨论（如「你用 Transformer 解决过什么实际问题？」）
- 定期清理潜水（连续 2 个月无发言可移出），保持群活跃度

### 6.4 用户激励体系

| 行为 | 激励 |
|------|------|
| 完成一个 Phase 的课程 | 专属结业证书（电子版）+ 进入进阶群 |
| 文章留言被选入《你问我答》 | 精品 Prompt 合集 PDF |
| 在社群分享学习心得/项目 | 公众号推文引用 + 署名感谢 |
| 贡献代码改进/勘误 | GitHub Contributor 署名 + 专属推文感谢 |
| 邀请 5 人关注 | 课程知识体系思维导图高清版 |

## 七、微信公众号技术文章发布限制 & 应对方案

### 7.1 代码格式限制

| 限制 | 问题 | 应对方案 |
|------|------|----------|
| 不支持 Markdown 渲染 | 直接粘贴代码无高亮、无行号，可读性极差 | **首选**：Carbon 生成代码截图；**备选**：墨滴/WeChat Format 渲染后粘贴 |
| 单篇文章代码字符限制 | 超过 20000 字符的代码可能被截断 | 长代码拆分多篇；核心代码文字版 + 完整代码见 GitHub |
| 不支持代码块内换行样式 | 长行代码在小屏手机上展示差 | 代码截图宽度 ≤ 600px；文字版代码每行 ≤ 60 字符 |

### 7.2 外链限制

| 限制 | 问题 | 应对方案 |
|------|------|----------|
| 个人订阅号外链受限 | 认证前无法直接插入外链 | 使用「阅读原文」跳转；文末放短链接（如 gh-proxy 代理 GitHub）；引导「回复关键词」获取链接 |
| 外链在某些场景不显示 | 非白名单域名可能被屏蔽 | GitHub → Gitee 镜像双链；关键资源可上传到公众号素材库 |
| 不支持锚点链接 | 无法链接到文章内特定位置 | 使用文章内合集标签替代；文末统一汇总关键链接 |

### 7.3 内容审核风险

AI 相关内容在微信平台的潜在敏感点：

| 风险点 | 建议 |
|--------|------|
| 「大语言模型」「LLM」关键词 | 无敏感，正常使用 |
| AI 自主系统/Agent 安全相关内容 | Phase 15/18 涉及安全对齐的内容，聚焦技术视角，避免社会评论 |
| 开源模型名称（LLaMA/GPT 等） | 无敏感，正常使用 |
| 爬虫/数据采集相关代码 | 加免责声明「仅用于学习研究，请遵守目标网站 robots.txt」 |
| 外网服务/API（OpenAI/Claude 等） | 可使用，但建议同时提供国内替代方案（通义千问/DeepSeek 等） |

### 7.4 图文消息限制

| 限制项 | 上限 | 说明 |
|--------|------|------|
| 单篇图文字数 | ~20000 字 | 建议控制在 3000-5000 字/篇 |
| 图片数量 | 无硬性限制 | 建议 8-15 张/篇，太多了加载慢 |
| 视频 | 单篇 1 个 | 代码演示可用 GIF 代替 |

### 7.5 其他应对建议

1. **认证服务号 vs 订阅号**：技术连载适合用订阅号（每天可发），服务号每月 4 次不够。优先认证订阅号获取更多接口权限。
2. **多图文**：每周可用一次多图文（主文 + 附文），附文放总结/资源汇总。
3. **素材库管理**：建立统一的图片/代码截图素材库，按 Phase 编号归档。
4. **数据统计**：利用微信公众号后台的「单篇数据」分析哪些 Phase/主题阅读量最高，调整后续内容重心。

### 8.2 变现方式详解

#### 方式一：赞赏（零门槛，即刻启用）

- 每篇文章开启赞赏
- 赞赏引导语：「如果这篇文章帮你省了一本教材的钱，欢迎赞赏支持」
- 预期：技术深度文赞赏率 0.5%-2%

#### 方式二：知识星球（第 4 个月启动）

| 内容 | 定价 |
|------|------|
| 完整 503 节课的深度解析 + 答疑 | ¥199/年 |

| 每月 1 次直播答疑 | - |
| 星球专属 Prompt/Skill 工具包 | - |
| 学习打卡 + 进度追踪 + 结业证书 | - |

#### 方式三：付费专栏/合集（第 6 个月启动）

- 微信付费文章功能：部分 Phase 总结类文章设为付费（¥6.66-¥9.99）
- 高价值合集：如「从零手写 LLM 完整教程」付费合集 ¥49
- 策略：免费文章占 80%，付费精品占 20%

#### 方式四：在线课程/训练营（第 8-12 个月）

| 产品 | 形式 | 定价参考 |
|------|------|----------|
| 《AI 工程 14 天入门营》 | 社群 + 直播 + 作业批改 | ¥499-699 |
| 《LLM 工程师实战营》 | 录播 + 社群 + 项目评审 | ¥999-1499 |
| 《Agent 工程师特训》 | 录播 + 实战项目 + 1v1 辅导 | ¥1999-2999 |

#### 方式五：企业合作（第 12 个月+）

- **企业内训**：将课程定制化为企业 AI 团队培训方案（¥50K-200K/次）
- **技术顾问**：为企业 AI 转型提供技术咨询
- **品牌合作**：AI 云平台/MCP 工具厂商的软植入（标注「合作推广」）

#### 方式六：出版

- 20 个阶段结束后，整理为系列图书（预计 3-5 册）
- 与人民邮电出版社（异步社区）/ 机械工业出版社等 AI 技术书强社合作
- 预期稿酬：首印 3000-5000 册，版税 8-10%

### 8.3 变现节奏控制原则

> ⚠️ **核心原则**：永远让免费内容保持最高质量。付费是锦上添花，不是雪中送炭。

- 公开推送的质量不能因为有了付费内容而下降
- 付费内容 = 额外的深度 + 便利性 + 互动，而非把免费内容藏起来
- 赞赏/星球/付费文章的收入 30% 用于社群运营和奖品

## 十、风险与注意事项

### 10.1 版权风险

- 源项目为 MIT 协议，允许商用、修改、分发，仅需保留版权声明
- 每篇文章末尾标注源项目链接和 MIT 协议声明
- 翻译内容需注意：「改编自」「基于」≠「原创」，明确标注来源

### 10.2 内容质量风险

- **翻译质量**：技术术语使用中文 AI 社区通用译名（如 Backpropagation→反向传播，Tokenization→分词）
- **代码舛误**：严格执行 BUILD IT → USE IT 验证流程，确保代码可运行
- **时效性**：AI 领域发展极快，课程中涉及前沿架构（如 2026 年最新的 Attention Variants）定期检查是否有更新

### 10.3 运营风险

- **持续产出**：500+ 节课是马拉松，建立内容团队（翻译 + 排版 + 运营）是必要的
- **社区负向**：AI 领域观点分歧大（开源 vs 闭源、RLHF vs DPO），保持技术中立
- **平台政策变化**：关注微信公众号规则更新，特别是外链、内容审核政策变化
