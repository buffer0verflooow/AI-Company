# 公众号封面模板系统 · AI工程从零开始

> **版本**: v1.0  
> **目标平台**: 微信公众号（主平台）  
> **品牌**: AI工程从零开始 (AI Engineering from Scratch)  
> **设计基础**: 沿用源项目配色与风格——蓝图/技术手册美学

---

## 一、封面尺寸规范

| 类型 | 尺寸 (px) | 适用场景 | 安全区说明 |
|------|----------|---------|-----------|
| **头条封面** | `900 × 383` | 公众号推送头条（封面大图） | 核心信息放在中央 600×300 区域内，避免被标题遮挡 |
| **次条封面** | `200 × 200` | 次条推送（方形小图） | 圆形裁切风险高，核心元素放中心 120×120 区 |
| **分享卡片** | `500 × 400` | 微信转发/朋友圈分享 | 下方 80px 可能被转发者昵称遮挡 |
| **合集封面** | `900 × 383` | 文章系列合集 | 与头条统一，但可更简洁（纯系列标识） |

> ⚠️ 关键提醒：微信公众号 2026 年现行封面裁剪规则——头条封面以 2.35:1 比例展示，但消息列表中的缩略图会裁剪为 1:1 方形。**务必确保封面图在 1:1 裁剪后核心信息仍可辨识。**

### 2.3 设计基因（来自源项目风格分析）

1. **Blueprint 美学**：类蓝图/技术手册风格——网格点阵背景、FIG_编号体系、虚线边框
2. **几何体装饰**：同向透视图块（平行四边形堆叠），代表「层层构建」
3. **底部色条签名**：封面底部 6px 高的水平规则色条，加入浅灰色横线
4. **FIG_XXX 编号体系**：每张图左上角标注 `FIG_XXX` 编号，延续技术手册感

**几何体设计规则**:
1. **堆叠平行四边形**: 7 个同向平行四边形块，从右下方向左上方逐层缩小（象征 Phase 堆叠）
   - 每块透明度从 6% → 18%（最顶层最深）
   - 描边：`#3553ff` 1.2px
   - 整体位于封面右侧 40-50% 区域
2. **连接虚线**: 从最顶层几何体引出水平虚线 → 连接到左侧标题区（`stroke-dasharray="3 3"`, `#3553ff`, 0.8px）
3. **底部点阵线**: 几何体下方，横贯封面的点状装饰线

**Phase 可视化区分**:
- 每个 Phase 在几何体堆叠中「点亮」对应层级（该层不透明度升至 35%）
- 比如 Phase 14 → 堆叠中第 14 层（从下往上数）加亮

**设计要点**:
- 主标题靠左（左对齐，左侧留 60px margin）
- 几何体不进入 1:1 方形裁剪区（中央 200×200）
- 200×200 裁剪后：显示主标题 + Phase 编号 + 部分几何体顶端

## 四、封面文案规范

### 4.1 主标题规则

| 规则 | 说明 | 示例 |
|------|------|------|
| 字数上限 | ≤ 16 字（含标点） | ✅ 「Agent 的灵魂只有 120 行代码」 |
| 分行动态 | 8 字以内单行，9-16 字双行 | 双行时第二行字数 ≥ 第一行的 60% |
| 核心关键词 | 必须包含该 Phase 最核心概念 | Transformer / Agent / LLM / 梯度下降 |
| 避免词 | 「教程」「指南」「详解」「入门」——不是标题党 | ✅ 用概念本身做标题，不加修饰 |
| 吸引力公式 | 数字 + 反差 + 承诺 | 「500 行代码手写 Transformer」 |

### 4.2 副标题规则

- 字数：10-20 字
- 作用：补充主标题的具体范围
- 颜色：`#7a7a78`（不与主标题抢视觉权重）
- 格式：`从 [范围] 到 [产出]` 或 `[具体内容]的[形容词]解析`

### 4.3 底部元信息

```
格式: AI工程从零开始 · 第[N]篇 · Phase [XX]
字体: JetBrains Mono, 11px, letter-spacing: 2.4px
颜色: #3553ff
位置: 底部色条上方 12px
对齐: 居中或左对齐（视风格而定）
```

### 4.4 系列统一元素（每期必须出现）

1. ✅ 左上角 FIG_编号: `FIG_0XX.A/B/C — AI ENGINEERING FROM SCRATCH · PHASE XX`
2. ✅ 底部 6px 色条
3. ✅ 「AI工程从零开始」品牌名
4. ✅ Phase 编号（大号 + 小号至少各出现一次）
5. ✅ 分区配色（按 Phase 所在区段选择点缀色）

## 六、制作指南（给设计师）

### 6.1 源文件格式

- 主文件：Figma / Adobe Illustrator `.ai`
- 导出：PNG（900×383, 200×200）+ SVG（网站/合集用）
- 字体：如使用 VT323 / JetBrains Mono（Google Fonts 免费），确保嵌入或转曲

### 6.2 Figma 组件建议

创建 Figma 组件库，包含：
- `封面-基础画板`（900×383 + 200×200 双画板 linked）
- `编号行组件`（带 instance swap 切换 Phase 编号和色彩）
- `底部色条组件`（色彩切换）
- `几何体堆叠组件`（用于风格 B，含可见性开关）
- `代码编辑器组件`（用于风格 C，含代码文本替换）

### 6.3 一次性生成 20 期封面的工作流

1. 在 Figma 中创建 3 个封面的主模板（A/B/C）
2. 使用 Google Sheets → Figma 插件批量替换：
   - 主标题文本
   - 副标题文本
   - Phase 编号
   - 代码片段（风格 C）
   - 点缀色
3. 批量导出 PNG → TinyPNG 压缩
4. 最终文件命名：`cover-phase-00-环境工具链-头条.png` / `cover-phase-00-环境工具链-次条.png`

### 6.4 色彩转换

| 名称 | HEX | RGB | CMYK（如需印刷） |
|------|-----|-----|-----------------|
| 品牌蓝 | `#3553ff` | 53, 83, 255 | 79, 67, 0, 0 |
| 纸白 | `#fafaf5` | 250, 250, 245 | 0, 0, 2, 2 |
| 墨黑 | `#1a1a1a` | 26, 26, 26 | 0, 0, 0, 90 |
| 灰 | `#7a7a78` | 122, 122, 120 | 0, 0, 2, 52 |
