## 一、发布前检查清单

|---|--------|---------|----------|

### 2.2 从主封面到各平台的派生关系

```
主封面 (900×383 PNG)
  │
  ├── 直接使用 ────→ 微信公众号头条封面 (900×383)
  │               → 微信公众号合集封面 (900×383)
  │
  ├── 居中裁切 ────→ 微信公众号次条封面 (200×200)
  │               从中心裁切 200×200 方形区域
  │
  ├── 缩放适配 ────→ 知乎专栏封面 (800×400)
  │               等比缩放至宽度 800px，上下加 8.5px 留白
  │
  ├── 重新构图 ────→ B站视频封面 (1146×717)
  │               需重新设计为视频封面风格（加播放按钮、频道Logo）
  │
  ├── 变换比例 ────→ 小红书封面 (1080×1440)
  │               需重新设计为竖版 3:4（完全不同的构图）
  │
  └── Open Graph ──→ 网站分享卡片 (1200×630)
                   用于个人网站/博客的 SEO 元标签
```

| 内容类型 | 首选格式 | 备选 | 说明 |

## 三、发布日操作流程

### 3.1 发布前 24 小时

```
☐ 1. 文章定稿（Markdown 源文件）
☐ 2. 所有配图生成完毕（封面 + 信息图 + 代码截图 + GIF）
☐ 3. 配图上传至公众号素材库（避免发布时 404）
☐ 4. 用 md2wx 或第三方工具转换 Markdown → 公众号富文本
☐ 5. 手机预览第一轮（自己 + 1 位同事）
☐ 6. 修正排版问题
☐ 7. 知乎/CSDN 版本同步排版
```

### 3.2 发布前 2 小时

```
☐ 1. 手机预览第二轮（覆盖不同机型）
☐ 2. 检查所有外链可访问
☐ 3. 检查封面在不同裁剪下的显示
☐ 4. 填写文章摘要 + 合集标签
☐ 5. 确认定时发布时间：周三 20:00
☐ 6. 准备微信群/朋友圈转发文案
```

### 3.3 发布后 1 小时内

```
☐ 1. 检查文章在手机上实际显示效果
☐ 2. 知乎/CSDN 同步发布
☐ 3. 技术交流群转发 + 互动
☐ 4. 将原文链接归档到 Notion/飞书文档库
```

## 四、问题排查速查表

| 常见问题 | 可能原因 | 解决方案 |
|---------|---------|---------|
| 封面模糊 | 原始图片分辨率不够 | 封面必须 ≥ 900×383px 原始尺寸 |
| 代码截图文字模糊 | 截图时缩放比不对 | 用 Carbon 导出 2x 分辨率 |
| 信息图在手机上字太小 | 设计时按桌面端字号 | 信息图正文 ≥ 13px (1080px 宽下) |
| 封面圆形裁切后看不懂 | 核心信息在四角 | 核心信息放在中央 120×120 安全区 |
| 图片上传后颜色变灰 | 色彩空间不匹配 | 导出时用 sRGB 色彩空间 |
| Mermaid 图在手机上断行 | 节点文字太长 | 节点文字 ≤ 15 个字符 |
| GIF 太大上传失败 | 帧数多 + 分辨率高 | 减少至 3-5 秒循环，宽度 ≤ 600px |
| 知乎公式渲染失败 | LaTeX 语法不兼容 | 用知乎原生公式编辑器重新输入 |
| 暗色模式下图片有白框 | 图片有白色背景不是透明 | 确保 PNG 背景透明，或接受白底 |
| 分享卡片显示旧封面 | 微信缓存 | 在文章链接后加 `?t=timestamp` 参数 |
