# JD 技能 ↔ 攻击面 ↔ 公司资产映射表

> 用途：把真实 JD 提出的技能作为公司 AI 安全方向，知识积累挂在攻击面坐标系上（而非散点收集）。
> 原则：JD 技能是「入场券语言」（市场需求侧），攻击面是「护城河坐标系」（技术侧）——互相翻译，不互相替代。
> 数据源：2026-08-16 智联抓取 19 条 AI 安全核心岗 JD 技能画像（提及次数）。

## 1. 映射表（核心交付物）

| JD 技能 | 攻击面定位（坐标系） | 公司现有资产（证据） | 缺口 / 建设方向 |
|---|---|---|---|
| 评测体系(31) | 方法维（横跨全部八面） | P5 验证门（判据化/双轮复核/脱钩复现）；MARBLE 基准 F1=1.0；验收标准模板（product-incubation） | **P3 升维**：从「蜂群内部验证」→「Agent 安全评测方法论」，输出评测报告样张（服务前身）。军科院/中电科 JD 原话「安全评测体系、量化指标、准出标准」= 市场需求 |
| Agent 攻防(20+) | 输入面 + 工具面 + 通信面 | 蜂群审计 F1-F8/M1/M2（注入链/工具权限/身份校验全链实证）；llm-security skill（OWASP LLM Top10 + ASI2026） | **P1 加固闭环**：A19 鉴权、M1/M2 标记 → 修复实录即攻防案例；华为 JD「Agent 攻防红队」直接对标 |
| 提示词注入/越狱/对抗(45) | 输入面 + 模型面 | 蜂群实测经验（~45% 发现占比）；Fable5 降级文（含越狱/记忆劫持实测） | 建可复现的注入/越狱测试用例库（对齐军科院「自动化测试工具」JD） |
| 投毒/后门/窃取(14) | 记忆面 + 供应链面 | PoisonedRAG 90% 操控实测；Fable5 记忆投毒实证；Weaponized Memory 素材（08-13 情报） | **差异化位**：记忆投毒检测器（master-plan P2 第二候选）——「空库更易写入」反直觉点是独有角度 |
| 隐私/联邦/差分(12) | 模型面（防御侧） | 暂无实证 | **知识积累区**：国家电投 JD 明确要联邦学习/多方安全计算/差分隐私——蜂群暂无此能力，列为 P2 知识补课（读论文+实验笔记→文章） |
| 运营治理/SOC(26) | 治理侧（横跨） | 内容产线 C 赛道文章（治理向）；security_intel 情报系统 | 文章选题素材池已有（C1-C12 治理向待发）；JD 侧「AI 安全运营 SOP」= 企业语言，衔接 P4 变现 |
| 预训练/微调(15) | 模型面（底层） | 无（公司不做模型训练） | **判断：不追**——永达电子 3-6 万 JD 要求「只招底层预训练内核」，与公司定位（攻防/评测）错位；保持了解级即可（Fable5 降级文已覆盖路由层知识） |
| 证书合规 | — | 无 | P2 补课（career-gap 差距6）：CISSP/CISP 企业语言 |

## 2. 建设优先级（按 市场需求 × 差异化 × 现有资产 三维）

| 优先级 | 方向 | 理由 |
|---|---|---|
| P0 | 评测体系方法论 | JD 第一高频(31) + 公司 P5 验证门已具雏形 + master-plan P3 已规划 → 一鱼三吃（能力/服务前身/面试谈资） |
| P0 | Agent 攻防案例化 | 华为/军科院/平安 JD 全部要求 + 蜂群审计 F1-F8 现成实证 → 直接产出《自建 233-agent 系统安全审计》案例 |
| P1 | 记忆投毒检测 | 差异化位 + PoisonedRAG/Fable5 实证在手 + master-plan P2 第二候选 → 输出检测器 + 文章 |
| P1 | 隐私/联邦/差分知识积累 | 市场需求明确（国家电投）但公司空白 → 补课型积累（论文→实验笔记→文章），不追预训练 |
| P2 | 证书合规 | 企业语言缺口，纯补课，时间靠后 |

**明确不追**：大模型预训练/底层内核（永达电子类 JD）——与公司攻防+评测定位错位，需求画像不代表公司方向，只是市场观测。

## 3. 知识积累机制（不动知识库结构，只挂标签）

每个技能的积累闭环（沿用 master-plan §4 产出闭环）：

```
JD 技能 → 定位攻击面（本表第1列） → 蜂群审计/实验实证
        → 检测器(防) → P5 验证 → KB 条目(带攻击面+技能标签) → 文章(传)
```

- 选题登记时：文章/实验/检测器必须引用本表「攻击面定位」列（防回到看到什么是什么）
- 情报采集时：TRACK_RULES 命中技能簇（评测/投毒/Agent攻防/隐私）→ 进选题池
- 面试/简历时：本表 = 能力与市场需求的对齐清单（每行一个可讲案例）
