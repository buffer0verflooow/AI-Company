# 视频创作产线 — 市场调研与规划报告

> 编制：战略部

## 1. 市场现状

### 1.1 B站技术类内容竞争格局

B站是中国技术视频消费的核心平台。2026 年技术区（知识区·科技类）的核心数据（基于公开可查信息）：

| 指标 | 估计值 | 说明 |
|------|:---:|------|
| 科技区日均活跃 UP 主 | 5-8 万 | 含编程、AI、网络安全、硬件 |
| 头部 AI/编程 UP 主粉丝量 | 50万-500万 | 如「不高兴就喝水」「码农高天」等 |
| 中部技术 UP 主粉丝量 | 5万-50万 | 细分领域专家，内容深度好 |
| AI 话题视频平均播放 | 5万-50万 | 2025-2026 AI 热度推高 |

**内容缺口分析**（待通过 B站搜索指数验证）：

- ✅ 已有大量 AI 入门/科普内容（「什么是 Transformer」「ChatGPT 原理」）
- ✅ 已有 LLM 应用教程（「用 LangChain 搭 Agent」「本地部署 DeepSeek」）
- ⚠️ 缺乏 **从代码出发的系统化教学**（逐行解读、手写实现）
- ⚠️ 缺乏 **AI Agent 工程实战**（生产级 Agent 搭建、MCP 协议实战）
- ⚠️ 缺乏 **AI + 安全攻防** 的深度内容（LLM 逆向 EDR、混淆对抗）

**这正是 ai-edu-series 和 article-curation 项目的覆盖领域。**

### 1.2 小红书技术类内容

小红书技术内容以图文为主，视频为辅。AI/编程类笔记互动量高（千赞级常见），但深度不如 B站。视频内容以 1-3 分钟精华剪辑为主，适合做 B站长视频的二次分发。

### 1.3 抖音技术类内容

抖音编程/AI 类内容以 1 分钟以内高强度钩子视频为主。流量天花板高但内容深度要求低，适合做品牌曝光而非深度教学。目前不是优先平台。

## 2. 目标受众

### 核心画像

| 受众 | 占比估计 | 特征 | 内容需求 |
|------|:---:|------|------|
| AI/ML 开发者（1-3年） | 40% | 会用框架但不懂原理 | 系统化、能逐行看懂的深度教程 |
| 计算机专业学生 | 30% | 学过基础，缺工程实践 | 从零手写、项目驱动的实战内容 |
| 安全从业者 | 20% | 做渗透/蓝队，关注 AI+安全 | AI 辅助攻防、EDR 逆向等前沿方向 |
| 技术管理者 | 10% | 不做一线开发，需判断趋势 | 技术边界判断、架构决策参考 |

### 与文章产线受众的关系

文章产线的受众 = 视频产线的种子用户。视频是文章的**视觉延伸**——文章提供深度，视频提供可看性。两条产线互相导流。

## 3. 成本估算

### 单条视频成本（代码走读型，15-25 min）

| 环节 | 方式 | 估计成本 |
|------|------|:---:|
| 脚本撰写 | `technical-writer` 代理 | ~$0.50 API 费 |
| 配音 | Hermes `text_to_speech` | ~$0.10 |
| 画面录制 | VS Code 录屏 + 自动剪辑 | $0（工具免费） |
| 字幕生成 | `voice-ai-integration-engineer` + Whisper | ~$0.30 |
| 封面生成 | Python PIL | $0 |
| 质检审核 | Hermes 主代理 | ~$0.50 |
| **合计** | | **~$1.40/条** |

### 概念动画型（3-8 min，Manim）

| 环节 | 额外成本 |
|------|:---:|
| 动画脚本 | codex 代理生成 Manim 代码 | ~$2-5 |
| 渲染 | 本地 GPU（已有） | $0 |
| **合计增量** | | **~$3-6/条** |

### 批量生产成本

随着流程标准化，边际成本会下降。核心优化方向：
- 脚本可复用文章产线的质检通过稿
- 封面模板化（一次设计，多次使用）
- 剪辑自动化（FFmpeg 批处理）

**每月 4 条视频（周更）的月度成本：$5-25**。单人公司完全可承受。

## 4. 竞争分析

### 差异化定位

| 维度 | 现有技术 UP 主 | 本产线（AI 代理驱动） |
|------|------|------|
| 内容来源 | 个人知识积累 | 503 节系统课程 + 海外前沿文章 |
| 更新频率 | 周更~月更（受个人精力限制） | 周更可保证（代理池 7×24 生产） |
| 内容深度 | 取决于 UP 主个人水平 | 多代理交叉验证，质量稳定 |
| 视觉质量 | 取决于剪辑投入 | 代码走读为主，视觉朴素但信息密度高 |
| 特色 | 个人风格 | **系统化 + 工程视角 + AI 原生工作流** |

**核心壁垒**：不是比别人做得好，是比别人**系统**。503 节课的体系是现有 UP 主难以复制的。

## 5. 盈利模型

### 短期（试点期，第 1-3 个月）

| 变现方式 | 可行性 | 说明 |
|------|:---:|------|
| B站流量分成 | ⭐⭐ | 粉丝 < 1 万时收入可忽略 |
| 公众号导流 | ⭐⭐⭐ | 视频引导关注公众号，间接变现 |
| 知识星球/付费社群 | ⭐⭐ | 需要粉丝基础后才有转化 |

### 中期（成长期，第 4-12 个月）

| 变现方式 | 可行性 | 说明 |
|------|:---:|------|
| B站充电/课程 | ⭐⭐⭐⭐ | 将 20 篇 ai-edu-series 视频化后打包为付费课程 |
| 品牌商单 | ⭐⭐⭐ | 粉丝 > 5 万后有 AI 工具/云服务商单机会 |
| 咨询/培训 | ⭐⭐⭐ | 企业 AI Agent 培训需求旺盛 |

### 长期（成熟期，1 年后）

| 变现方式 | 可行性 | 说明 |
|------|:---:|------|
| 自研课程平台 | ⭐⭐⭐⭐ | 文章 + 视频 + 代码 + 在线练习 = SaaS 产品 |
| 企业订阅 | ⭐⭐⭐ | 团队版内容 + 内部培训 |

**结论：视频产线的商业化路径清晰但不是急迫事项。前 6 个月的核心目标是建立内容品牌和粉丝基础，而后变现自然发生。**

## 6. 风险与应对

| 风险 | 概率 | 影响 | 应对 |
|------|:---:|:---:|------|
| 内容质量不稳定 | 中 | 高 | 复用文章产线的三 Gate 质检流程 |
| B站算法推荐不稳定 | 中 | 中 | 多平台分发，不依赖单一平台 |
| 配音听感差（TTS） | 高 | 中 | 试点期试听效果，必要时换人工录音 |
| 版权问题（使用源项目内容） | 低 | 高 | 源项目 MIT 协议，需保留版权声明 |
| 视频制作耗时超过预期 | 中 | 中 | 从最简单的代码走读形态开始，逐步加动画 |
| AI 话题热度下降 | 低 | 中 | 不追热点，做长青内容（基础比热点寿命长） |

## 7. 发展路线图

### Phase 1：试点期（第 1-2 个月）

**目标**：跑通一条视频的完整流程，验证工作流可行性。

| 里程碑 | 交付物 |
|------|------|
| 搭建视频工具链 | OBS 录屏 + Whisper 字幕 + FFmpeg 剪辑环境就绪 |
| 制作首条视频 | 基于 #01「Agent 的灵魂只有一个不到 200 行的循环」的代码走读视频 |
| B站账号开通 | 完成账号注册、分区选择、首条投稿 |
| 数据验证 | 收集播放量、完播率、互动数据，判断方向 |

### Phase 2：成长期（第 3-6 个月）

**目标**：稳定周更，积累 5000+ 粉丝。

| 里程碑 | 交付物 |
|------|------|
| 周更节奏确立 | 每周 1-2 条视频稳定产出 |
| 视频类型拓展 | 从代码走读拓展到概念动画（Manim） |
| 多平台分发 | B站长视频 + 小红书精华剪辑 + 抖音高光切片 |
| 粉丝基础建立 | B站粉丝 5000+ |

### Phase 3：成熟期（第 7-12 个月）

**目标**：内容品牌建立，开始尝试变现。

| 里程碑 | 交付物 |
|------|------|
| 20 节课程视频化 | ai-edu-series 全部视频化，打包为付费课程 |
| 商单尝试 | 首个品牌合作 |
| 课程上线 | B站充电课程或独立平台 |

## 8. 建议与下一步行动

### 核心结论

> **视频产线值得投入。** 成本极低（$5-25/月）、与文章产线高度互补（内容复用、互相导流）、市场存在差异化空间（系统化教学缺口）。风险可控，失败成本几乎为零。

### 下一步行动（本周）

1. **搭建录屏环境** — 安装 OBS，配置 VS Code Monokai Pro 主题 + 16+ 字号
2. **测试配音** — 用 Hermes `text_to_speech` 生成 #01 文章摘要的配音，评估听感
3. **制作首条视频脚本** — 从 #01 文章中提取代码走读片段，改写为视频脚本
4. **注册 B站账号** — 完成分区选择、简介、头像
5. **首条投稿** — 不追求完美，先跑通流程

### 暂缓事项

- 小红书/抖音分发 → 等 B站有基础量后再切
- Manim 动画 → 第三条视频之后再引入
- 变现规划 → 6 个月后再启动
